# job-text

Created in [T3 Code](https://t3.codes).

Paste a LinkedIn job link, get the posting as plain text to copy. Live at https://kcgbarbosa.github.io/job-text/

The page fetches the posting through [r.jina.ai](https://jina.ai/reader/) and cleans it in `clean.js`. Run the cleaner tests with `node --test`.
